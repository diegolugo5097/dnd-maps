# Sonidos de poderes

Coloca aquí tus archivos MP3 con el formato: `{tipo}-spell.mp3`

## Archivos esperados:
- `fire-spell.mp3`       → Bola de fuego y Muro de fuego
- `ice-spell.mp3`        → Tormenta de hielo
- `lightning-spell.mp3`  → Rayo
- `poison-spell.mp3`     → Nube venenosa y Lluvia ácida
- `earth-spell.mp3`      → Muro de tierra
- `holy-spell.mp3`       → Aura sagrada
- `darkness-spell.mp3`   → Oscuridad y Aura de muerte
- `water-spell.mp3`      → Inundación
- `wind-spell.mp3`       → Torbellino
- `acid-spell.mp3`       → Lluvia ácida (opcional, sino usa poison)
- `necrotic-spell.mp3`   → Aura de muerte (opcional, sino usa darkness)

Si un archivo no existe, se usará síntesis de audio procedural automáticamente.
