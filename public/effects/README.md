# Efectos GIF por poder

Coloca aquí tus GIFs animados con el formato: `{poder-id}.gif`

## Archivos esperados:
- `fire.gif`        → Bola de fuego
- `fire_wall.gif`   → Muro de fuego
- `ice.gif`         → Tormenta de hielo
- `lightning.gif`   → Rayo
- `poison.gif`      → Nube venenosa
- `earth.gif`       → Muro de tierra
- `holy.gif`        → Aura sagrada
- `darkness.gif`    → Oscuridad
- `water.gif`       → Inundación
- `wind.gif`        → Torbellino
- `acid.gif`        → Lluvia ácida
- `necrotic.gif`    → Aura de muerte

Si un GIF no existe, se usa el color sólido del poder como respaldo.
Los GIFs se escalan para cubrir exactamente el área pintada (object-fit: cover).
